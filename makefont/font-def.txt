#
#  font defintion file for "LED Matrix" style fonts.
#  Syntax rules:
#
#   #-lines and blank lines are ignored.
#   .DIRECTIVE abc - sets/adds directive abc, see below...
#
# 
#   DEF # x  -> starts definition of character code "#" (0-255) and the display 
#               version "x" (x can be omitted if equal to ASCII char!)
#               All lines (including empty!) following the DEF one are treated
#               as part of the char matrix, like so: blanks are "off" pixels,
#               non-blanks are "on" pixsls. Any columns or lines missing 
#               will be assumed "off"; no traling spaces/lines needed.
#               Only a line starting with "DEF" or "." terminates the line block.
#
#   Directives:
#   .FORMAT  ->  specify the width and height of the font's matrix. 
#                5x7 = 5 columns, 7 lines. Currently, 32 maximum for both!
#
#   .NAME -> The font's name - some font formats want a name, this is it.
#
#   .COPY -> The copyright message for the font.
#
#   .REM -> Remarks to be added. Can occur multiple times, will form a text 
#           block if needed.
#
